# ESG-Quant AI 기반 기업 건전성 평가 및 정책 연계 시스템 보고서

---

## 2.1 기술목적

본 기술은 비재무적 ESG 데이터를 정량화하고 인공지능 기반 분석을 통해 기업의 실질적인 건전성을 평가하는 것을 목적으로 합니다. 기존 기업 평가는 재무제표 중심의 사후적 지표에 의존하여 기업의 지속가능성, 사회적 책임, 지배구조 리스크 등을 충분히 반영하지 못하는 한계가 있습니다.

또한 ESG 데이터는 다음과 같은 구조적 문제를 가지고 있습니다.

- 비정형 데이터 중심으로 구성되어 정량화가 어려움  
- 기업 간 공시 기준 불일치로 비교 가능성이 낮음  
- 데이터 출처 간 정보 충돌로 신뢰성 저하 발생  

본 시스템은 다음을 통해 이러한 문제를 해결합니다.

- ESG 데이터의 정량화 및 표준화  
- AI 기반 미래 리스크 예측  
- 공정성과 설명 가능성을 갖춘 평가 체계 구축  
- 정책 및 금융 의사결정과 직접 연계 가능한 평가 지표 제공
